Algorithmic Invariants
✔ Sentinel Nodes: Dummy Head and Tail eliminate null pointer boundary errors.
✔ Access Update: Whenever a key is accessed (`get`), it moves to the Tail (most recently used).
✔ Capacity Eviction: When full, remove `head.next` in O(1) time.
⚠️ AI Bug Analysis (Root Cause)

When updating an existing key in `put()`, failure to remove the stale node first causes duplicate nodes and incorrect eviction order.
